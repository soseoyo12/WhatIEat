# WhatIEat — 오늘 뭐 먹지?

휴대폰을 흔들면 룰렛이 돌아가고, 오늘 먹을 음식과 그 음식을 파는 인하대 주변 식당을 알려주는 iOS 네이티브 앱.

## 무엇을 만드는가

### 핵심 흐름

```
📱 휴대폰을 흔든다
   ↓
🎡 음식 룰렛이 돌아간다  (37개 음식 카테고리)
   ↓
🍚 오늘의 음식이 정해진다  (예: 찌개·백반)
   ↓
🏪 그 음식을 파는 주변 식당을 보여준다
   → 식당 이름 · 대표 메뉴 · 가격 · 평점 · 거리
   ↓
🗺️ 지도에서 위치를 확인한다
```

### 기능 목록

- **흔들기 감지** — 기기를 흔드는 동작을 감지해 룰렛을 시작
- **음식 룰렛** — 37개 음식 카테고리 중 하나를 뽑는 회전 애니메이션
- **식당 추천** — 당첨된 카테고리를 취급하는 식당을 거리·평점 기준으로 정렬해 제시
- **상세 정보** — 메뉴별 가격, 카카오/다이닝코드 평점, 리뷰 수, 캠퍼스로부터의 거리
- **지도 표시** — MapKit으로 식당 위치를 앱 안에서 바로 확인

## 데이터

앱은 **서버 없이 오프라인으로 동작한다.** 식당 정보는 사전 조사해 앱 번들에 내장한 JSON을 `Codable`로 파싱해 사용한다.

### 조사 결과 (`research/inha-food-guide/`)


| 항목          | 수치                        |
| ----------- | -------------------------: |
| 조사 범위       | 인하대 캠퍼스 반경 1km · 미추홀구 용현동 |
| 식당          | 177곳                      |
| 음식 카테고리     | 37개                       |
| 카테고리별 메뉴    | 1,448건                    |
| 카테고리 대표 이미지 | 37장                       |
